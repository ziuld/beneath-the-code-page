## F01-UH01 — Build the Java baseline reproducibly

As a maintainer, I want to build the imported project from a clean checkout, so that another contributor can reproduce the application.

Parent: F01. Priority: Must. Status: done. Owner: Ziuld with AI assistance.
Estimate: 6h baseline / 6h forecast. Dependencies: F00.

Implements the accepted feature scope; no additional product capabilities implied.

| ID | Pattern | Required behaviour |

## F01-UH02 — Protect dependency boundaries and review entry

Parent: F01. Priority: Must. Status: blocked. Owner: Ziuld with AI assistance.
Estimate: 4h baseline / 4h forecast. Dependencies: F01-UH01.

Implements the accepted feature scope; no additional product capabilities implied.

### EARS requirements

| ID | Pattern | Required behaviour |
|---|---|---|
| F01-UH02-R01 | unwanted | If domain code imports a Spring type, then architecture verification shall fail. |
| F01-UH02-R02 | event | When a pull request runs Java verification, the CI job shall report its actual verification outcome. |
