## F20-UH01 — Portable Docker Desktop handoff and final closure

As a project owner, I want to develop and run the application in Docker, so that host toolchain versions do not determine the workflow.

Parent: F20. Priority: Must. Status: done. Owner: Ziuld with AI assistance.
Estimate: 8h baseline / 8h forecast. Dependencies: F19.

Bounded V2 follow-up under ADR010. Planned checks are not passing evidence. Preserve the accepted V1 baseline and existing functionality. Owner clarification 2026-10-21: support ongoing development from Windows/Linux Docker checkouts with containerized Java/Node/Python tooling; retain a separate runtime image for later VPS work. No VPS deployment is authorised here. Host/platform claims require actual evidence. Owner decision 2026-10-21: tested local execution is sufficient for current acceptance; second-PC testing is no longer a closure gate. Future cross-PC problems are bugs; untested platforms remain unverified.
