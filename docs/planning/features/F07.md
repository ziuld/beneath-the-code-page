## F07-UH01 — Validate strict JSON

As a developer, I want to check whether text is valid JSON, so that I can identify syntax errors before using the document.

Parent: F07. Priority: Must. Status: planned. Owner: Ziuld with AI assistance.
Estimate: 5h baseline / 5h forecast. Dependencies: F06.

Implements the accepted feature scope; no additional product capabilities implied.

### EARS requirements

| ID | Pattern | Required behaviour |
|---|---|---|
| F07-UH01-R01 | event | When a valid JSON document is validated, the validator shall report a localised valid status. |
| F07-UH01-R02 | unwanted | If a document contains JSON comments, then the validator shall report it as invalid JSON. |

## F07-UH02 — Minify JSON without changing tokens

As a developer, I want to remove unnecessary JSON whitespace, so that I obtain compact content without data changes.

Parent: F07. Priority: Must. Status: planned. Owner: Ziuld with AI assistance.
Estimate: 5h baseline / 5h forecast. Dependencies: F07-UH01.

Implements the accepted feature scope; no additional product capabilities implied.

### EARS requirements

| ID | Pattern | Required behaviour |
|---|---|---|
| F07-UH02-R01 | event | When a valid JSON document is minified, the minifier shall preserve every non-whitespace token. |
| F07-UH02-R02 | unwanted | If JSON is invalid, then the minifier shall refuse to publish a new successful output. |

### Gherkin acceptance scenarios

[Standalone Gherkin file](../gherkin/F07-UH02.feature). Specifications only: no step definitions or Cucumber runtime have been installed.

```gherkin
@EPIC-MVP @F07 @F07-UH02
Feature: F07-UH02 — Minify JSON without changing tokens
  As a developer, I want to remove unnecessary JSON whitespace, so that I obtain compact content without data changes.

  @F07-UH02-AC01 @F07-UH02-R01
  Scenario: Preserve whitespace inside a string
    Given the document contains a string whose value is a b
    When the developer minifies the document
    Then the space inside the string remains while insignificant whitespace is removed

  @F07-UH02-AC02 @F07-UH02-R02
  Scenario: Do not minify a broken document
    Given a previous successful result exists and the input becomes invalid
    When the developer requests minification
    Then the old result is marked stale and cannot be copied as the new result
```
