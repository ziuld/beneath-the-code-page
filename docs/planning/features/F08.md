## F08-UH01 — Encode and decode UTF-8 Base64

As a developer, I want to convert UTF-8 text to and from Base64, so that I can inspect encoded text locally.

Parent: F08. Priority: Must. Status: planned. Owner: Ziuld with AI assistance.
Estimate: 6h baseline / 6h forecast. Dependencies: F06.

Implements the accepted feature scope; no additional product capabilities implied.

### EARS requirements

| ID | Pattern | Required behaviour |
|---|---|---|
| F08-UH01-R01 | event | When valid UTF-8 text is encoded and then decoded, the Base64 tool shall return the original text. |
| F08-UH01-R02 | unwanted | If encoded input has invalid alphabet or padding, then the decoder shall report a localised error. |
