## F13-UH01 — Navigate a course and its published lessons

As a learner, I want to browse Java Fundamentals and move between lessons, so that I can follow a coherent learning path.

Parent: F13. Priority: Must. Status: done. Owner: Ziuld with AI assistance.
Estimate: 8h baseline / 5h forecast. Dependencies: F07.

Verify infrastructure with synthetic single/multi-unit fixtures; enable production Learn navigation only with F14's reviewed unit. No extra published units, CMS or speculative catalogue framework. ADR009: Chromium-only MVP browser acceptance; Firefox/WebKit optional post-MVP evaluation.

### EARS requirements

| ID | Pattern | Required behaviour |
|---|---|---|
| F13-UH01-R01 | event | When a learner opens a published lesson, the page shall provide its course context and valid previous or next lesson navigation where available. |
| F13-UH01-R02 | unwanted | If a lesson slug is unknown or unpublished, then Beneath the Code shall return a localised 404. |

## F13-UH02 — Read localised course content safely

As a learner, I want to read clear course content in my selected language, so that I can learn without unsafe embedded markup.

Parent: F13. Priority: Must. Status: done. Owner: Ziuld with AI assistance.
Estimate: 8h baseline / 5h forecast. Dependencies: F13-UH01-T01.

Use local EN/ES/FR resources and safe shared rendering. Infrastructure acceptance uses synthetic fixtures; actual technical and language review of the first unit belongs to F14. ADR009: Chromium-only MVP browser acceptance; Firefox/WebKit optional post-MVP evaluation.

### EARS requirements

| ID | Pattern | Required behaviour |
|---|---|---|
| F13-UH02-R01 | state | While a supported language is selected, a published lesson shall render its reviewed content in that language. |
| F13-UH02-R02 | unwanted | If source content contains raw executable HTML, then the content renderer shall prevent that markup from executing. |

### Gherkin acceptance scenarios

[Standalone Gherkin file](../gherkin/F13-UH02.feature). Specifications only: no step definitions or Cucumber runtime have been installed.

```gherkin
@EPIC-MVP @F13 @F13-UH02
Feature: F13-UH02 — Read localised course content safely
  As a learner, I want to read clear course content in my selected language, so that I can learn without unsafe embedded markup.

  @F13-UH02-AC01 @F13-UH02-R01
  Scenario: Read the Spanish lesson
    Given a synthetic published lesson fixture has complete Spanish content
    When the learner opens it with Spanish selected
    Then the title, prose and exercise instructions are in Spanish

  @F13-UH02-AC02 @F13-UH02-R02
  Scenario: Treat embedded script as untrusted markup
    Given a synthetic Markdown fixture contains a script element
    When the lesson renderer processes it
    Then no executable script from the fixture appears in the rendered lesson
```
