## F18-UH01 — Page-by-page design agreement and implementation

As a website visitor, I want to use clearer and more attractive pages, so that I can read lessons and use tools comfortably.

Parent: F18. Priority: Must. Status: in_progress. Owner: Ziuld with AI assistance.
Estimate: 12h baseline / 28h forecast. Dependencies: F17, F15-UH02.

Owner explicitly approved the integrated F18 review checklist on2026-10-21. Reviewed runtime/test/JAR hashes unchanged; automated gates PASS. T05 complete; T06 recording scoped local reviewed revision and closure. Original12h baseline/28h forecast preserved; actual effort unreported.

### EARS requirements

| ID | Pattern | Required behaviour |
|---|---|---|
| F18-UH01-R01 | event | When a page design is explored, the assistant shall provide a prompt grounded in the actual page for owner-generated Nano Banana concepts and record the agreed design before implementation. |
| F18-UH01-R02 | event | When agreed designs are implemented and consolidated, the website shall use one shared design system across all pages while preserving routes, core tool operations, EN/ES/FR, privacy, keyboard access and responsive behaviour. |
| F18-UH01-R03 | event | When a maintainer changes a shared style token or component variant in its owning definition, the website shall propagate that change to all uses of the same role or variant without per-page style patches. |
