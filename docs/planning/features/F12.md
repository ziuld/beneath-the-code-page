## F12-UH01 — Discover the complete published tool suite

As a visitor, I want to find and open each available developer tool, so that I can choose the right operation.

Parent: F12. Priority: Must. Status: planned. Owner: Ziuld with AI assistance.
Estimate: 6h baseline / 6h forecast. Dependencies: F07, F08, F09, F10, F11.

Implements the accepted feature scope; no additional product capabilities implied.

### EARS requirements

| ID | Pattern | Required behaviour |
|---|---|---|
| F12-UH01-R01 | event | When the complete tool catalogue is opened, Beneath the Code shall list all eight accepted Phase 1 tools with working destinations. |
| F12-UH01-R02 | unwanted | If an unknown tool identifier is requested, then Beneath the Code shall return a localised 404. |

## F12-UH02 — Run the complete tools locally in a hardened container

As a maintainer, I want to run a reproducible local container, so that I can verify the integrated application without cloud infrastructure.

Parent: F12. Priority: Must. Status: planned. Owner: Ziuld with AI assistance.
Estimate: 8h baseline / 8h forecast. Dependencies: F12-UH01.

Implements the accepted feature scope; no additional product capabilities implied.

### EARS requirements

| ID | Pattern | Required behaviour |
|---|---|---|
| F12-UH02-R01 | event | When the documented local Compose workflow starts, the application shall become healthy using only loopback-published application access. |
| F12-UH02-R02 | unwanted | If an integrated security scan reports an unresolved blocking finding, then release verification shall fail. |

[Standalone Gherkin file](../gherkin/F12-UH02.feature). Specifications only: no step definitions or Cucumber runtime have been installed.

  As a maintainer, I want to run a reproducible local container, so that I can verify the integrated application without cloud infrastructure.

  @F12-UH02-AC01 @F12-UH02-R01
  Scenario: Start the local runtime
    Given the pinned image is built and documented prerequisites are available
    When the maintainer starts the Compose service
