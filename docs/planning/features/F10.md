## F10-UH01 — Inspect a JWT without implying signature verification

As a developer, I want to decode JWT header and claims locally, so that I can inspect a token without mistaking decoding for validation.

Parent: F10. Priority: Must. Status: planned. Owner: Ziuld with AI assistance.
Estimate: 8h baseline / 8h forecast. Dependencies: F06.

Implements the accepted feature scope; no additional product capabilities implied.

### EARS requirements

| ID | Pattern | Required behaviour |
|---|---|---|
| F10-UH01-R01 | event | When a supported compact JWS is decoded, the JWT tool shall display its header and payload with a signature-not-verified notice. |
| F10-UH01-R02 | unwanted | If the token uses unsupported five-part JWE format, then the decoder shall report that encrypted-token decoding is unsupported. |
