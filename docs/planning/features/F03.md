## F03-UH01 — Understand the Home page and discover available sections

As a visitor, I want to understand Beneath the Code from its Home page, so that I can choose practical tools or engineering education.

Parent: F03. Priority: Must. Status: planned. Owner: Ziuld with AI assistance.
Estimate: 8h baseline / 8h forecast. Dependencies: F02.

Implements the accepted feature scope; no additional product capabilities implied.

### EARS requirements

| ID | Pattern | Required behaviour |
|---|---|---|
| F03-UH01-R01 | event | When a visitor requests the Home page, Beneath the Code shall return semantic server-rendered content describing its tools and learning purpose. |
| F03-UH01-R02 | unwanted | If a section has no published destination, then the Home page shall present that section without a broken actionable link. |

```gherkin
  As a visitor, I want to understand Beneath the Code from its Home page, so that I can choose practical tools or engineering education.

  @F03-UH01-AC01 @F03-UH01-R01
  Scenario: Read Home without JavaScript
    Given JavaScript is disabled
    When a visitor opens the Home page
    Then the response contains the brand identity, a main heading and the tools and learning descriptions

  @F03-UH01-AC02 @F03-UH01-R02
  Scenario: Avoid advertising an unavailable destination
    Given a tools or learning destination has not been published in the current increment
    When a visitor inspects the Home navigation
    Then the section is described without a link to a missing page
```

## F03-UH02 — Use the shared interface in each supported language

As a visitor, I want to read and navigate a consistent accessible interface, so that language or input method does not prevent me using the platform.

Parent: F03. Priority: Must. Status: planned. Owner: Ziuld with AI assistance.
Estimate: 10h baseline / 10h forecast. Dependencies: F03-UH01.

Implements the accepted feature scope; no additional product capabilities implied.

### EARS requirements

| ID | Pattern | Required behaviour |
|---|---|---|
| F03-UH02-R01 | state | While a supported locale is active, the shared interface shall render its labels from that locale's message resources. |
| F03-UH02-R02 | event | When a keyboard user navigates the shared interface, the interface shall expose visible focus on every reachable control. |

### Gherkin acceptance scenarios

[Standalone Gherkin file](../gherkin/F03-UH02.feature). Specifications only: no step definitions or Cucumber runtime have been installed.

```gherkin
@EPIC-MVP @F03 @F03-UH02
Feature: F03-UH02 — Use the shared interface in each supported language
  As a visitor, I want to read and navigate a consistent accessible interface, so that language or input method does not prevent me using the platform.

  @F03-UH02-AC01 @F03-UH02-R01
  Scenario: Render French interface labels
    Given the resolved locale is French
    When the Home page is rendered
    Then its navigation and accessibility labels use French resources and no unresolved message keys

  @F03-UH02-AC02 @F03-UH02-R02
  Scenario: Navigate without a mouse
    Given the Home page is at a narrow viewport and the user uses only a keyboard
    When the user traverses the shared navigation and controls
    Then focus remains visible and the user can reach and leave every control
```
