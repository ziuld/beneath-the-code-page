# F06 — JSON Formatter

Parent: **EPIC-MVP**. Status: **planned**. Kind: product.

Baseline/forecast: 24/24 owner hours. Prerequisites: F05.

## Feature purpose

This feature delivers the following outcomes: Format valid JSON without changing its data; Correct invalid or oversized JSON safely; Copy or clear the formatter workspace deliberately.

Scope remains bounded by the [feature summary](../feature-backlog.md) and [accepted architecture](../../architecture/technical-architecture-v1.md). Account, database, cloud and SPA work is excluded.

## F06-UH01 — Format valid JSON without changing its data

As a developer, I want to format valid JSON while preserving its tokens, so that I can inspect documents without corrupting their values.

Parent: F06. Priority: Must. Status: planned. Owner: Ziuld with AI assistance.
Estimate: 10h baseline / 10h forecast. Dependencies: F05.

Implements the accepted feature scope; no additional product capabilities implied.

### EARS requirements

| ID | Pattern | Required behaviour |
|---|---|---|
| F06-UH01-R01 | event | When a developer formats valid JSON, the formatter shall change only insignificant whitespace. |
| F06-UH01-R02 | state | While JSON formatting is performed, the formatter shall keep the input and result inside browser memory. |

### Gherkin acceptance scenarios

[Standalone Gherkin file](../gherkin/F06-UH01.feature). Specifications only: no step definitions or Cucumber runtime have been installed.

```gherkin
@EPIC-MVP @F06 @F06-UH01

  As a developer, I want to format valid JSON while preserving its tokens, so that I can inspect documents without corrupting their values.

  @F06-UH01-AC01 @F06-UH01-R01
  Scenario: Preserve an unsafe JavaScript integer
    Given the input is {"id":9007199254740993}
    When the developer formats with two-space indentation
    Then the output retains the numeric token 9007199254740993

  @F06-UH01-AC02 @F06-UH01-R02
  Scenario: Process a private sentinel locally
    Given the formatter contains a unique synthetic sentinel and all initial assets are loaded
    When the developer formats the document
    Then no operation-triggered request is made and the sentinel is absent from persistent storage and application logs
```

## F06-UH02 — Correct invalid or oversized JSON safely

As a developer, I want to receive actionable errors without losing my input, so that I can correct a document and retry.

Parent: F06. Priority: Must. Status: planned. Owner: Ziuld with AI assistance.
Estimate: 8h baseline / 8h forecast. Dependencies: F06-UH01.

Implements the accepted feature scope; no additional product capabilities implied.

### EARS requirements

| ID | Pattern | Required behaviour |
|---|---|---|
| F06-UH02-R01 | unwanted | If JSON syntax is invalid, then the formatter shall preserve the input and show a localised diagnostic with its location. |
| F06-UH02-R02 | unwanted | If input exceeds the configured input limit, then the workspace shall reject its insertion with localised feedback. |

### Gherkin acceptance scenarios

[Standalone Gherkin file](../gherkin/F06-UH02.feature). Specifications only: no step definitions or Cucumber runtime have been installed.

```gherkin
@EPIC-MVP @F06 @F06-UH02
Feature: F06-UH02 — Correct invalid or oversized JSON safely
  As a developer, I want to receive actionable errors without losing my input, so that I can correct a document and retry.

  @F06-UH02-AC01 @F06-UH02-R01
  Scenario: Explain a trailing comma
    Given the input is {"id":1,}
    When the developer requests formatting
    Then a localised syntax diagnostic identifies the error and the original input is unchanged

  @F06-UH02-AC02 @F06-UH02-R02
  Scenario: Reject oversized paste before editor work
    Given the editor contains a small valid document
    When the developer pastes more than 1 MiB of UTF-8 content
    Then the oversized replacement is rejected and the previous input remains available
```

## F06-UH03 — Copy or clear the formatter workspace deliberately

As a developer, I want to copy the current result or clear the workspace, so that I control what leaves the tool through my clipboard.

Parent: F06. Priority: Must. Status: planned. Owner: Ziuld with AI assistance.
Estimate: 6h baseline / 6h forecast. Dependencies: F06-UH02.

Implements the accepted feature scope; no additional product capabilities implied.

### EARS requirements

| ID | Pattern | Required behaviour |
|---|---|---|
| F06-UH03-R01 | event | When the developer activates Copy on a current successful result, the workspace shall copy exactly that result to the clipboard. |
| F06-UH03-R02 | event | When the developer clears the workspace, the workspace shall remove the current input and output from its active editor state. |

### Gherkin acceptance scenarios

[Standalone Gherkin file](../gherkin/F06-UH03.feature). Specifications only: no step definitions or Cucumber runtime have been installed.

```gherkin
@EPIC-MVP @F06 @F06-UH03
Feature: F06-UH03 — Copy or clear the formatter workspace deliberately
  As a developer, I want to copy the current result or clear the workspace, so that I control what leaves the tool through my clipboard.

  @F06-UH03-AC01 @F06-UH03-R01
  Scenario: Copy current result
    Given formatting has produced a current successful output
    When the developer activates Copy
    Then the clipboard receives that output and a localised success status is announced

  @F06-UH03-AC02 @F06-UH03-R02
  Scenario: Clear a running workspace
    Given the workspace contains input and a job is running
    When the developer activates Clear
    Then input and output become empty and a late job result does not repopulate them
```
