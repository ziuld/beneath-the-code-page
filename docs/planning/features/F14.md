## F14-UH01 — Understand the first unit scope and learning outcomes

As a learner, I want to see the first unit prerequisites and learning outcomes, so that I understand what this published unit teaches without mistaking it for a complete course.

Parent: F14. Priority: Must. Status: planned. Owner: Ziuld with AI assistance.
Estimate: 6h baseline / 2h forecast. Dependencies: F13.

Implements the accepted feature scope; no additional product capabilities implied. ADR009: Chromium-only MVP browser acceptance; Firefox/WebKit optional post-MVP evaluation.

### EARS requirements

| ID | Pattern | Required behaviour |
|---|---|---|
| F14-UH01-R01 | event | When the first unit is published, the course overview shall state its prerequisites and learning outcomes and identify the course as containing one available unit. |
| F14-UH01-R02 | unwanted | If additional course units are not reviewed and published, then the course overview shall not present them as available or claim course completion. |

## F14-UH02 — Learn the source-to-JVM mental model

Parent: F14. Priority: Must. Status: planned. Owner: Ziuld with AI assistance.
Estimate: 12h baseline / 8h forecast. Dependencies: F14-UH01.

Implements the accepted feature scope; no additional product capabilities implied. ADR009: Chromium-only MVP browser acceptance; Firefox/WebKit optional post-MVP evaluation.

### EARS requirements

| ID | Pattern | Required behaviour |
