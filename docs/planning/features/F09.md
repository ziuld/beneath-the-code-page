## F09-UH01 — Generate bounded cryptographic UUID v4 values

As a developer, I want to generate UUID v4 values locally, so that I can create identifiers without sharing them.

Parent: F09. Priority: Must. Status: planned. Owner: Ziuld with AI assistance.
Estimate: 4h baseline / 4h forecast. Dependencies: F06.

Implements the accepted feature scope; no additional product capabilities implied.

### EARS requirements

| ID | Pattern | Required behaviour |
|---|---|---|
| F09-UH01-R01 | event | When a developer requests a supported batch size, the UUID tool shall generate that number of UUID v4 values using a cryptographic browser API. |
| F09-UH01-R02 | unwanted | If the requested batch size is outside 1 through 100, then the UUID tool shall reject the request. |
