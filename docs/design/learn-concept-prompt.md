## Copy into Nano Banana

Create a high-fidelity website design concept for the Learn landing page of
“Beneath the Code”, a software-engineering education and developer-tools website.
The feeling should be thoughtful, distinctive and inviting: an independent
technical publication with a carefully designed learning library.

Deliver a desktop layout at 1440px width and a matching mobile layout at 390px
width, presented side by side. Render readable interface text. Show the actual
webpage, without device frames, photography, perspective effects or mood-board clutter.

Preserve the brand: near-black canvas #050505, subtly separated surfaces #0B0B0B
and #111111, warm off-white text #EDEAE4, readable secondary text and fine borders.
Use a refined serif for a moderately sized editorial headline, clean sans-serif
for body/navigation, and restrained monospace for small technical metadata. Keep
the supplied B identity exact; use its contour/wireframe motif sparingly as an
original-brand reference, away from reading text. Avoid neon or glowing effects.

Build this page around:
1. A calm header with Beneath the Code, Home / Tools / Learn, Learn visibly active,
   and an English / Español / Français language selector with Apply control.
2. A clear introductory section: small label “LEARN”, headline “Understand what
   happens beneath the code.” and short copy “Build your understanding of software
   engineering through clear explanations and practical examples.”
3. One generously spaced course card titled “Java Fundamentals”. Give it a short
   description, “3 units available” metadata and one clear “Explore course” action.
   This action opens the existing course overview. The course is still growing.
4. Inside the course presentation, show a quiet preview of the three available
   units, in order: “From Java source to the JVM”; “Values, types and numeric
   limits”; “Control flow and tracing”. Treat these as units of one course.
5. A restrained footer with “Understanding over memorisation.”

Make the composition richer through typography, alignment, subtle depth and a
small purposeful technical motif, rather than adding features. Use roughly
64–96px between major desktop sections, 28–40px card padding, and comfortable
18px body text. On mobile use 20–24px side gutters, stack the layout naturally,
and let controls and translated labels wrap. Balance breathing room with useful
content density; avoid both cramped blocks and a giant mostly empty hero.

Keep text contrast strong, buttons clearly identifiable, and a visible keyboard
focus treatment. Accommodate longer Spanish/French labels and enlarged text.
There are no accounts, dashboards, saved progress, certificates, ratings, search,
filters, invented courses or student statistics. Do not show unsupported features.
The result should feel achievable as a responsive website with ordinary links
and semantic content, with the existing functionality intact.
